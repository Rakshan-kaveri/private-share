# Legacy: Private Share v5

This folder keeps the previous version for reference. It is **not** used by the current app or its Docker build.

v5 was a file-transfer-only app built from a Spring Boot backend, a React/Vite frontend and nginx.
v6 replaced all three with one dependency-free Node.js server and a plain-JavaScript client, and added
voice calls, video calls and screen sharing. See [CHANGELOG.md](../CHANGELOG.md) for what changed and why.
